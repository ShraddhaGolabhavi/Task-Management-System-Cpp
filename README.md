# Task Management System (C++)

This is a console-based **Task Management System** built in C++ using Object-Oriented Programming.  
It allows users to create tasks, assign them to users, track deadlines, send notifications, and update task status.

---

## 🚀 Features

### ✔ Task Management
- Create tasks with title and description  
- Print all tasks  

### ✔ User Management
- Create users with name and email  
- Assign tasks to users  
- View all users and their assigned tasks  

### ✔ Assignment System
- Assign task → user  
- Record assignment time  
- Track status (Assigned / Completed)  

### ✔ Deadline Tracking
- Set deadlines for tasks  
- Check if deadline is crossed  
- Auto-generate notifications  

### ✔ Notifications
- Alerts for missed deadlines  
- View all generated notifications  

### ✔ Mark Task as Completed
- User can update task status to "Completed"  

---

## 🧱 Technologies Used
- **C++**
- **OOP (Classes, Inheritance, Encapsulation)**
- Console-based input/output
